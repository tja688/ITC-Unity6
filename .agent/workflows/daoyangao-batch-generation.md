# 剧本导演稿批量生成工作流 (Daoyangao Batch Generation Workflow)

本工作流用于指导 AI Assistant 如何使用 `daoyangao-generator` 技能，将《地狱转运公司 (ITC)》的原始剧本批量、安全、高质量地转化为带有“节拍”和“五维韵律”的导演稿。

## 核心原则与限制

1. **绝对忠实原句：** 不得增删改原标点、错别字或任何非系统说明的文字内容。所有的导演指示（五维参数、强调词）只能通过规定的极简符号插入到原句中。
2. **遵守单次 Token 限制：** 每次 AI 输出不得超过 32,000 Tokens上限。为了留足安全边际量，**建议每次生成包含的原始剧本节点不超过 10-15个“场景（## 场景）”或约 150-200 行原始 Markdown 文本**。
3. **分卷拆解：** 遇到大章节（特别是数百个节点的“签约”章），必须按照逻辑段落或场景节点数进行物理拆分（例如：第三章_签约_1.md, 第三章_签约_2.md ... 第三章_签约_N.md）。
4. **强制自检：** 每次完成一部分生成并准备输出（Write File）前，Assistant 应在思考环节进行自我 review，确认原句无改动、五维填满且强调词不超限。

## 工作流步骤

### Step 1: 认领生成区块 (Claim Chunk)
- 使用此工作流的 AI Agent 首先查看 `分P切割规划计划.md`。
- 定位当前需要处理的区块（例如 Part X），读取该区块在 `ITC_完整剧本_清洗版.md` 中的起始与结束行号（或场景号）。

### Step 2: 研读区块内容与上下文 (Read Context)
- 使用 `view_file` 工具读取分配到的原始剧本文本。
- 理解当前区块的角色出场状态、情绪基调以及核心矛盾。

### Step 3: 应用 Daoyangao 技能解析 (Skill Execution)
- 严格遵循 `c:\Users\jinji\Documents\GitHub\ITC-Unity6\ITC-Unity6\.agent\skills\daoyangao-generator\SKILL.md` 的规范。
- 逐句（指每一条含对白的台词或重要的旁白/动作指示）进行五部分输出：
  1. 题头：`### （说话人 → 对象）台词：<原句片段>`
  2. **信息栏**：1句话总结当下压力与目标。
  3. **节拍表**：切分 B1...Bn，写明 `〔动词：To xxx〕` + `〔G档位〕` + `〔速〕` + `（潜台词）` + `强调：【】` + `收束箭头` + `停顿`。
  4. **正文（标注版）**：原封不动保留原句，插入上述符号。
  5. **备选演法（如有必要）**：针对关键节点提供另一套方案。

### Step 4: Token 限度内输出 (Safe Write)
- 将这一批量的解析结果拼接为 Markdown 文档。
- 输出文件命名规范：`[章节号]_[章节名]_[分P号].md` （比如：`第三章_签约_5.md`）。
- 使用写入文件工具产出内容。

### Step 5: 汇报与推进 (Report & Next)
- 告知用户该 Chunk 已完成（或通知下一个工作流线程接力）。
- 当当前章节全部分解完毕后，更新并推进到下一个大章节计划。
