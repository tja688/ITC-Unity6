# ITC 原画提示词文档 (Background Art Prompts)

**文档说明**：
本文档基于 `ITC_原画需求表.md` 与 `ITC原画提示词模版.md` 生成。
旨在为 AI 作画工具 (如 Midjourney, Stable Diffusion) 提供标准化的提示词，以生成符合《ITC》游戏风格的背景原画。

**核心风格参数 (Fixed Parameters)**：
- **Art Style**: 2D vector art, flat colors, cel-shading, indie game background asset, visual novel background, comic book style
- **Lighting/Colors**: amber and orange color palette, sunset lighting, monochromatic warm tones, golden hour, high contrast, solid pitch-black shadows, no gradients
- **Lineart**: thick outlines, hard edges, crisp shapes, stylized geometric forms, simplified textures
- **Vibe**: steampunk, industrial revolution aesthetic, retro-futurism, mechanical vibe
- **Negative Prompt**: --no 3d render, realistic, photorealistic, gradient shading, soft shadows, watercolor, oil painting, messy lines, modern architecture, neon lights, cold colors
