# 剧本导演稿分P切割规划计划
> 基于《ITC_完整剧本_清洗版.md》

## 核心拆分原则
经过前两次实测，生成导演稿所需的 Token 量约为原始输入文本长度的 **40-50倍**（包括元信息、Markdown 骨架、节拍表设计、五维标注等）。
为了确保每次生成稳定在 32,000 Token 以内，且为大模型推理留足够余地，**单次切割区块（Chunk）的行数建议控制在 150-200 行，或约 10-15 个普通剧情`## 场景`节点内**。

由于 `ITC_完整剧本_清洗版.md` (共约 2008 行) 包含极长连续的剧本流，特制定以下分卷批处理计划：
