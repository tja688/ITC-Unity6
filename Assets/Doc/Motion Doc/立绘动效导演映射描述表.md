## 2. 逐效果导演映射（详细）

说明：每条都按“情绪、意图、触发语境、导演备注”描述，供剧本AI挑选演出时使用。

### 2.1 `MOTION_DOT_01_VerticalNod`
- 情绪表达：赞同、礼貌、温和确认。
- 表演意图：向对方传达“我接受你的信息”并让对话顺畅推进。
- 典型语境：`“嗯。”`、`“好，我知道了。”`、礼貌回应。
- 导演备注：这是低冲击确认动作，适合日常对话，不用于冲突高点。

### 2.2 `MOTION_DOT_02_VerticalHappyBounce`
- 情绪表达：开心、兴奋、得到正反馈后的上扬。
- 表演意图：把“喜讯/被肯定”的瞬间外化成可见能量。
- 典型语境：`“太好了！”`、`“成功了！”`、期待达成。
- 导演备注：建议在高兴节点短促使用，避免连续多句都弹跳导致幼态化。

### 2.3 `MOTION_DOT_03_HorizontalNoShake`
- 情绪表达：否定、拒绝、明确划线。
- 表演意图：把“不同意”从文字升级为肢体结论。
- 典型语境：`“不行。”`、`“不要。”`、`“我拒绝。”`
- 导演备注：用于立场清晰的拒绝；若角色是含蓄拒绝，可改用`DOT_12`。

### 2.4 `MOTION_DOT_04_HorizontalHappySway`
- 情绪表达：愉快、轻松、心情舒展。
- 表演意图：给角色增加“悠然在场感”，让画面不僵硬。
- 典型语境：轻松闲聊、调侃、暧昧升温前的舒适段落。
- 导演备注：属于氛围型动作，不承载强剧情信息，避免用于危机段落。

### 2.5 `MOTION_DOT_05_AngryTremble`
- 情绪表达：压抑愤怒、紧绷、情绪临界前的震颤。
- 表演意图：强调“还没爆发，但已经快失控”。
- 典型语境：`“别再说了。”`、`“你最好停下。”`、强忍怒气。
- 导演备注：比直接前冲更克制；如果下一拍要爆发，可接`DOT_07`。

### 2.6 `MOTION_DOT_06_SurpriseBackLean`
- 情绪表达：震惊、突发受冲击、认知被打断。
- 表演意图：把“信息命中”可视化为后撤反应。
- 典型语境：真相揭露、突发事件、反转台词落点。
- 导演备注：适合“瞬间反应”；后面常接短停顿或追问台词。

### 2.7 `MOTION_DOT_07_EmphasisForwardPush`
- 情绪表达：强势强调、压迫推进、情绪前压。
- 表演意图：让关键台词具有“逼近观众/逼近对手”的力量。
- 典型语境：`“绝不。”`、`“你现在就回答我。”`、对峙高点。
- 导演备注：这是冲突强化器；同段落重复使用要控制次数。

### 2.8 `MOTION_DOT_08_EnterSlideIn`
- 情绪表达：入场、加入、打断式出现。
- 表演意图：明确角色“从场外到场内”的状态变化。
- 典型语境：新角色开口前、插话者进入、镜头切入角色。
- 导演备注：属于结构性动作，优先用于段落起点。

### 2.9 `MOTION_DOT_09_ExitSlideOut`
- 情绪表达：离场、抽离、结束发言权。
- 表演意图：让“这个角色暂时退出”被清晰感知。
- 典型语境：告别、决裂后离开、段落收束。
- 导演备注：可与台词句尾收束形成配对，增强章节感。

### 2.10 `MOTION_DOT_10_ZoomInApproach`
- 情绪表达：靠近、专注、关系距离缩短（可亲密或压迫）。
- 表演意图：把观众注意力拉到该角色，突出当下话语权。
- 典型语境：告白前逼近、审问时压近、关键告知。
- 导演备注：语义依上下文决定；同是靠近，可温柔也可威压。

### 2.11 `MOTION_DOT_11_ZoomOutLeave`
- 情绪表达：远离、退让、关系降温。
- 表演意图：表现情绪抽离或话题离场。
- 典型语境：`“算了。”`、`“到此为止。”`、从冲突转冷处理。
- 导演备注：常用于冲突后半拍，给画面留出“冷却空间”。

### 2.12 `MOTION_DOT_12_TiltConfused`
- 情绪表达：困惑、不解、试探性提问。
- 表演意图：把“我还没完全相信/理解”外化。
- 典型语境：`“你什么意思？”`、`“真的吗？”`、轻疑问。
- 导演备注：适合中低强度疑问；真惊吓建议用`DOT_06`。

### 2.13 `MOTION_DOT_13_RotateYTurnBack`
- 情绪表达：转身、背对、态度切断。
- 表演意图：表达“我不再正面回应你”。
- 典型语境：失望离去、强硬结束沟通、剧情转折。
- 导演备注：戏剧性较强，建议配合关键台词后置使用。

### 2.14 `MOTION_DOT_14_RotateXFallBack`
- 情绪表达：失衡、仰倒、夸张受击或崩溃。
- 表演意图：把“被冲垮”做成明显视觉句号。
- 典型语境：喜剧受击、精神打击、极端反应。
- 导演备注：风格化明显，正剧里使用需谨慎控制频次。

### 2.15 `MOTION_MAT_01_Breathing`
- 情绪表达：平稳呼吸、活体存在感。
- 表演意图：在“无大动作”时维持角色生命力。
- 典型语境：常驻待机、平静叙述、关系温和段落。
- 导演备注：最通用叠加底层，可与多数DOT效果并用。

### 2.16 `MOTION_MAT_02_HeartbeatPulse`
- 情绪表达：心跳加速、心动/惊慌、内在波动上升。
- 表演意图：展示“内心有冲击，但未必外放动作很大”。
- 典型语境：告白瞬间、恐惧临界、突发紧张。
- 导演备注：优先叠加在`DOT_06`、`DOT_07`、`DOT_10`上。

### 2.17 `MOTION_MAT_03_MeshWave`
- 情绪表达：眩晕、梦境、异常压迫、非日常状态。
- 表演意图：把场面从现实感拉向“心理/超现实层”。
- 典型语境：幻觉、精神冲击、诡异事件。
- 导演备注：风格强，建议短时使用，不宜长期开启。

## 3. 叠加策略（导演快速决策）

| 目标情绪 | 主动作建议（DOT） | 叠加建议（MAT） | 备注 |
|---|---|---|---|
| 日常自然 | `DOT_01` / `DOT_04` | `MAT_01` | 保持角色“活着”但不过戏。 |
| 轻喜悦 | `DOT_02` / `DOT_04` | `MAT_01` | 轻快、明亮、不需要强冲击。 |
| 坚决拒绝 | `DOT_03` | `MAT_01` | 若对抗升级，再接`DOT_07`。 |
| 压抑愤怒 | `DOT_05` | `MAT_02`（可选） | 先抖后冲是常见演出节奏。 |
| 突发震惊 | `DOT_06` | `MAT_02` | 冲击+内心脉冲，戏剧感最稳。 |
| 强势对峙 | `DOT_07` / `DOT_10` | `MAT_02` | 形成“逼近 + 心压”双重感。 |
| 异常/幻觉 | `DOT_14` / `DOT_13` | `MAT_03` | 非日常段落的高风格组合。 |

## 4. 面向未来扩展的接入规范

### 4.1 命名与稳定键
- 预制体名即稳定调用键（Key），后续剧本AI直接引用此键。
- DOTween类使用前缀：`MOTION_DOT_XX_名称`。
- 材质类使用前缀：`MOTION_MAT_XX_名称`。
- `XX`为两位递增编号，不复用历史编号。

### 4.2 新增演出必填元信息（建议）
新增任何预制体时，在本表追加一行，并至少提供以下字段：
- `effect_key`：预制体稳定键。
- `display_name`：导演可读名。
- `category`：`DOT` 或 `MAT`。
- `emotion_tags`：情绪标签（2~5个）。
- `intent_tags`：意图标签（2~5个，动词化，如“施压/安抚/拒绝”）。
- `scene_triggers`：典型触发语境（台词或分镜描述）。
- `style_weight`：`Low/Medium/High`（风格强度）。
- `combo_hint`：可叠加建议（可为空）。
- `anti_pattern`：不建议使用场景（避免误用）。

### 4.3 剧本AI选型优先级建议
- 先按`intent_tags`筛选（角色想“做什么”）。
- 再按`emotion_tags`细化（角色“是什么状态”）。
- 最后看`style_weight`决定是否要风格化升级。

- 本文档是导演层语义规范，不绑定具体调用指令格式。
- 若参数微调但“情绪与意图”不变，可只更新备注。
