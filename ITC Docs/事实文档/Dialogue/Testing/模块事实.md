# Dialogue Testing 子模块事实

最后更新时间：2026-03-22（Asia/Shanghai）

## 1. 子模块职责

- 为 Yarn 对话流程提供“节点跳转快测”能力。
- 不参与正式业务状态写入，只用于验证/调试。

## 2. 脚本清单（代码事实）

- `Assets/Scripts/Dialogue/Testing/YarnTestCatalog.cs`
- `Assets/Scripts/Dialogue/Testing/YarnDialogueFastForward.cs`

## 3. YarnTestCatalog 事实

- `YarnTestCatalog : ScriptableObject`。
- 持有 `List<YarnTestFileInfo>`，每条包含：
  - `yarnFileName`
  - `startNode`
  - `endNode`
  - `description`
  - `commandsUsed`
  - `variableNodes`
- `GetAllJumpableNodes()`：聚合去重后的 `startNode + variableNodes`。

## 4. YarnDialogueFastForward 事实

- 依赖 `DialogueRunner` 与可选 `YarnTestCatalog`。
- 点击按钮后行为：
  - 若对话运行中先 `dialogueRunner.Stop()`
  - 在 catalog 的可跳转节点列表中循环前进
  - 调 `StartDialogue(targetNode)` 快速切换节点

## 5. 边界说明

- 该子模块不改 `SignMiniGameFlowStateModel`。
- 该子模块不写 `$Route_*` 变量。
- 签约对话正式运行时代码已迁入 `Assets/Scripts/Sign/**`，不再驻留于 `Assets/Tests/Test scripts/**`。
- `Assets/Tests/Test scene/TestScene_sign UI test.unity` 当前是正式 `SignScene` 的发布源场景，但这属于场景资产事实，不新增测试脚本子模块事实。
