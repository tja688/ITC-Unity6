# Dialogue Sign 子模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 子模块职责

- 在签约场景提供“槽位式对话呈现”：
  - NPC 最新句 + 历史句双槽
  - 玩家/心理活动槽位
  - 选项区域对齐
- 接管并扩展 Yarn 运行时命令。
- 提供占位小游戏遮罩与继续输入阻塞能力。

## 2. 脚本清单（代码事实）

- `Assets/Scripts/Dialogue/Sign/SignDialogueSlotRuntime.cs`
- `Assets/Scripts/Dialogue/Sign/SignCtrlHoverDriver.cs`
- `Assets/Scripts/Dialogue/Sign/SignCtrlHoverHitbox.cs`

## 3. SignDialogueSlotRuntime 核心事实

### 3.1 功能开关与状态

- `enableSignSlotRouting`
- `suppressLegacyPresenterVisuals`
- 公开只读状态：
  - `IsRoutingEnabled`
  - `ShouldSuppressLegacyPresenterVisuals`
  - `IsContinueInputBlocked`（小游戏占位层运行中或选项阻塞时为 true）

### 3.2 角色路由

- 角色类型：`Auto / Npc / Player / Thought`
- 路由判断顺序：
  - 若收到 `itc_sign_role` 覆盖，则优先使用覆盖角色
  - 否则按 speaker 关键词判断玩家/NPC
  - 无 speaker 时按内容是否包含“内心/心声/thought/mind”判 Thought

### 3.3 Yarn 命令扩展

- `itc_sign_npc_enter`：切入 NPC 对话周期
- `itc_sign_npc_exit`：退出 NPC 对话周期
- `itc_sign_role`：设置角色覆盖
- `itc_sign_minigame`：显示占位小游戏遮罩（按配置键默认 `Y` 完成）

### 3.4 文本槽位与历史

- 维护 NPC 历史队列（有上限）。
- `Slot1` 固定显示最新 NPC 台词。
- `Slot2` 默认显示上一句，可在历史区滚轮翻阅并回弹。
- 玩家文本进入玩家槽位。

### 3.5 运行时修正

- 启动时会修正 `DialogueRunner` presenters 列表顺序，确保 `TALinePresenter` 在首位。
- 关闭 OptionFallthrough（反射方式设置 Runner 字段/属性）。

## 4. Hover 交互辅助事实

- `SignCtrlHoverDriver`
  - 自动构建透明 hitbox（`__CtrlHitbox`）
  - 支持 hover scale 动画、进入/退出时长、曲线、可选点击事件
  - 支持按图形边界自动拟合 hitbox（可包含 inactive Graphic）
- `SignCtrlHoverHitbox`
  - 仅负责转发 pointer enter/exit/click 到 driver

## 5. 与 Core 模块的耦合事实

- `TALinePresenter` 可将台词路由给 `SignDialogueSlotRuntime.RouteLine(...)`。
- `DialogueContinueHandler` 在继续输入前检查 `IsContinueInputBlocked`。
