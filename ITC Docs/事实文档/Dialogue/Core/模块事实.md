# Dialogue Core 模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 模块职责

- 提供统一对话面板 `ITCDialoguePanel`。
- 将 Yarn 命令桥接到视觉切换、小游戏流程和场景切换。
- 管理文本呈现、继续/快进输入、文本事件转发。

## 3. 入口与生命周期事实

- `DialogueSceneFlowLauncher` 在 `Start()` 中执行：
  - `ResKit.InitAsync()`
  - 按配置自动打开 `ITCDialoguePanel`
  - `ITCDialoguePanelData` 默认 `StartNode = "ITC_Start"`、`AutoStartOnOpen = true`

## 4. ITCDialoguePanel 命令桥接事实

### 4.1 视觉与场景命令

- `itc_bg`：切背景图。
- `itc_npc_main` / `itc_npc_avatar` / `itc_pc_avatar`：切换角色图。
- `itc_npc_main_hide` / `itc_npc_avatar_hide` / `itc_pc_avatar_hide`：隐藏对应图层。
- `itc_load_scene`：`SceneManager.LoadSceneAsync`。

### 4.2 小游戏命令

- `itc_doc_review`
- `itc_rune_typing`
- `itc_rune_verify`
- `itc_stamp_select`
- `itc_soul_collect`
- `itc_bean_sell`
- `itc_settlement`

统一模式（代码实装）：
- 先读 Yarn 变量，发送 BeginCommand。
- `UIKit.OpenPanelAsync<...>(UILevel.PopUI, assetBundleName: "sign_minigame_ui")`。
- 监听 Panel `OnCompleted` 回调发送 SubmitCommand。
- 超时（开面板或运行）触发 fallback payload，避免卡流程。
- 将 `SignMiniGameFlowStateModel` 中结果回写 Yarn 变量。

## 5. 文本呈现与输入事实

- `TALinePresenter`
  - 继承 `DialoguePresenterBase`。
  - 支持 `TextAnimator + Typewriter`。
  - 支持快进时禁用渐入特效优化。
  - 支持“前置管道标签（`|tag|`）”解析，并注入 Text Animator 默认特效标签。
  - 在 Sign 路由模式下，可关闭 legacy 文本层并把行路由到 `SignDialogueSlotRuntime`。
- `DialogueContinueHandler`
  - 支持鼠标、键盘、按钮触发继续。
  - 支持 Ctrl 快进节奏（最短展示时间 + 下一句延迟）。
  - 对 `SignDialogueSlotRuntime.IsContinueInputBlocked` 做阻塞判定。
- `TADialogueEvents`
  - 桥接 Typewriter 与 DialogueRunner 的事件到 UnityEvent。
  - 提供 Skip 期间事件过滤（Blacklist/Whitelist/BlockAll）。

## 6. 视觉资源解析事实

- `DialogueVisualCatalog` 定义映射：
  - 槽位：`Background / NpcMain / NpcAvatar / PcAvatar`
  - key -> bundle/asset/subSprite/fallbackKey
- `DialogueSpriteProvider` 加载策略：
  - 优先缓存
  - Editor Simulation 下可走 `editorAssetPath`
  - 否则通过 ResKit 异步加载 AssetBundle，再取 Sprite/SubSprite

## 7. 标记转换事实（YarnMarkupConverter）

- 目标：将 Yarn 标记转换到 Text Animator 标签体系。
- 内置映射示例：
  - `pause -> waitfor`（ms->s）
  - `waitinput -> waitinput`
  - `shake/wave/wobble/bounce/rainbow`
  - `playsound/camerashake`（事件型标签）

## 8. 关键变量读写事实（核心）

- 读：`$Route_CurrentClient`, `$DAY`, `$satisfaction`, `$Sign_mistake`, `$Route_BeanSoldCount`, `$Route_RuneVerifyResult`, `$Route_RuneVerifyDebuff`, `$money`, `$Nmber_of_sign_mistake`, `$Global_sign_mistake`。
- 写：`$Route_*` 各玩法结果 + `$satisfaction` + `$Sign_mistake` + 结算资金/失误累计变量。
