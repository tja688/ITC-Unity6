# Contracting.SoulCollect 模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 脚本清单（代码事实）

- `Assets/Scripts/Contracting/SoulCollect/SoulCollectPanel.cs`
- `Assets/Scripts/Contracting/SoulCollect/SoulCollectQuickTestLauncher.cs`
- `Assets/Scripts/Contracting/SoulCollect/SoulCollectGuideTag.cs`

## 2. 面板职责事实

- `SoulCollectPanel : UIPanel`
- 输入：`SoulCollectPanelData`
  - `RuntimeConfig`（目标、最小、最大、手感参数）
  - `ClientConfig`
- 输出：`SoulCollectResultPayload`

## 3. 状态机事实

- `SoulReveal`
- `Aiming`
- `PreviewPercent`
- `ConfirmSplit`
- `Resolve`
- `Completed`

## 4. 交互与判定事实

- 玩家通过拖拽/键盘调整分割线。
- 面板按配置对目标做吸附辅助（Aim Assist）。
- 提交时计算 `actualRaw` 与 `actualPercent`，按区间判断：
  - `< min` => `TooLow`
  - `> max` => `TooHigh`
  - 否则 `Normal`
- payload 输出：
  - `TargetPercent/MinPercent/MaxPercent`
  - `ActualPercent/ActualRawFloat`
  - `ResolveType`
  - `WasFallback=false`

## 5. 与全局流程连接事实

- 对话层先发 `BeginSoulCollectCommand`（写入本轮目标区间与基线状态）。
- 面板提交后由 `SubmitSoulCollectResultCommand` 更新：
  - `RouteSoulCollectPercent`
  - `RouteSoulMin/RouteSoulMax`
  - `Satisfaction/SignMistake`

## 6. QuickTest 与 GuideTag 事实

- `SoulCollectQuickTestLauncher`
  - 支持配置目标百分比、教程模式、基线状态
  - 热键重开默认 `Y`
  - 超时保护日志
- `SoulCollectGuideTag` 为引导标记空组件。
