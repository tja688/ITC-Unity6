# Contracting.BeanSell 模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 脚本清单（代码事实）

- `Assets/Scripts/Contracting/BeanSell/BeanSellPanel.cs`
- `Assets/Scripts/Contracting/BeanSell/BeanSellQuickTestLauncher.cs`
- `Assets/Scripts/Contracting/BeanSell/BeanSellGuideTag.cs`

## 2. 面板职责事实

- `BeanSellPanel : UIPanel`
- 输入：`BeanSellPanelData`
  - `ClientId/Day`
  - `RuntimeConfig`
  - `ClientConfig`
- 输出：`BeanSellResultPayload`

## 3. 状态机事实

- `Intro`
- `PitchChoosing`
- `Resolving`
- `Completed`

## 4. 判定公式事实（代码实装）

- 面板内部得分由以下项组合：
  - `baseWill = client.BuyWillingness`
  - `pitchBonus = 选中话术是否等于 PreferredPitch ? +2 : -1`
  - `weight = runtime.ResolvePitchWeight(pitchType)`
  - `situationalModifier = client.SituationalModifier`
- 成功条件：`finalScore >= runtime.SuccessThreshold`

## 5. 流程约束事实

- Day 未达到开启日时，上层会直接走 skipped，不开面板。
- 面板提交 payload（`WasFallback=false`）后由 SubmitCommand 收口。
- 提交后主要影响：
  - `RouteBeanSellResult`（success/failed/skipped）
  - `RouteBeanPitchType`
  - `RouteBeanSoldCount`
  - 失败时可能扣满意度（由 SubmitCommand 执行）

## 6. QuickTest 与 GuideTag 事实

- `BeanSellQuickTestLauncher`
  - 可配置 `clientId/day/基线已售数/基线满意度`
  - 热键重开默认 `B`
  - 包含 Day 不达标时的 skipped 快测路径
- `BeanSellGuideTag` 为引导标记空组件。
