# MainMenu 模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 模块职责

- 初始化 UI Kit + ResKit。
- 打开主菜单面板。
- 处理“开始新游戏 / 退出”入口交互。
- 触发进入对话面板（`ITCDialoguePanel`）。

## 3. 状态模型事实（MainMenuStateModel）

- `ResKitReady`
- `PanelOpenRequested`
- `PanelOpened`
- `DialoguePanelOpenRequested`
- `DialoguePanelOpened`

以上均为 `BindableProperty<bool>`，用于防重复开面板与流程状态同步。

## 4. 命令事实（MainMenuCommands）

- `MarkMainMenuResReadyCommand`：标记资源初始化完成。
- `OpenMainMenuPanelCommand`：打开 `MainMenuPanel`（`menu_core` 包）。
- `MarkMainMenuPanelOpenedCommand`：标记主菜单已打开。
- `RequestOpenDialoguePanelCommand`：打开 `ITCDialoguePanel`（`dialogue_ui` 包，默认 `StartNode=ITC_Start`），并关闭 `MainMenuPanel`。
- `MarkDialoguePanelOpenedCommand` / `MarkDialoguePanelClosedCommand`：维护对话面板开关状态。

## 5. 启动流程事实（MainMenuFlowLauncher）

- `Awake()`：`UIKit.Config = new MainMenuUIKitConfig()`。
- `Start()`：
  - 防重入（`bootstrapped`）
  - `yield return ResKit.InitAsync()`
  - 发送 `MarkMainMenuResReadyCommand`
  - 发送 `OpenMainMenuPanelCommand`
  - 可选自动演示流：等待面板打开后发 `RequestOpenDialoguePanelCommand`

## 6. 交互组件事实

- `MainMenuExitButton`
  - 基于对象名关键字区分按钮行为：
    - 包含“退出”：点击执行退出
    - 包含“开始新游戏”：点击请求打开对话
  - 带 Hover 缩放反馈。
- `MainMenuEntranceDrop`
  - 对菜单子节点按“从上到下”顺序做入场下落 + 渐显动画。
  - 支持 `unscaledTime`。

## 7. 依赖关系事实

- 对话入口依赖 `ITCDialoguePanel`（`ITC.Dialogue`）。
- `MainMenuApp` 同时注册合同流程模型（`SignMiniGameFlowStateModel`、`SignMiniGameClientConfigModel`），使主菜单和对话共享同一架构实例。
