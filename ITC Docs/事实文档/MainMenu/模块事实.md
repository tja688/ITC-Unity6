# MainMenu 模块事实

最后更新时间：2026-04-01（Asia/Shanghai）

## 1. 模块职责

- 作为项目当前主入口场景。
- 打开已经直接落在场景内的 `MainMenuPanel`。
- 处理“开始新游戏 / 退出”入口交互。
- 从主菜单切入签约主场景 `SignScene`。

## 2. 脚本清单（代码事实）

- `Assets/Scripts/MainMenu/MainMenuApp.cs`
- `Assets/Scripts/MainMenu/MainMenuStateModel.cs`
- `Assets/Scripts/MainMenu/MainMenuUIKitConfig.cs`
- `Assets/Scripts/MainMenu/MainMenuCommands.cs`
- `Assets/Scripts/MainMenu/MainMenuFlowLauncher.cs`

## 3. 状态模型事实（MainMenuStateModel）

- `ResKitReady`
- `PanelOpenRequested`
- `PanelOpened`
- `DialoguePanelOpenRequested`
- `DialoguePanelOpened`

以上均为 `BindableProperty<bool>`，当前主要用于入口防重入与状态同步。

## 4. 命令事实（MainMenuCommands）

- `MarkMainMenuResReadyCommand`
  - 当前仅标记主菜单入口逻辑 ready
  - 不再代表 ResKit 真正初始化完成
- `OpenMainMenuPanelCommand`
  - 当前通过 `Object.FindFirstObjectByType<MainMenuPanel>(FindObjectsInactive.Include)` 查找场景内 `MainMenuPanel`
  - 找到后直接 `SetActive(true)`
  - 不再通过 `menu_core` 包异步打开
- `MarkMainMenuPanelOpenedCommand`
  - 标记主菜单已打开
- `RequestOpenDialoguePanelCommand`
  - 当前不再打开 `ITCDialoguePanel` 资产包
  - 直接 `SceneManager.LoadScene("SignScene", LoadSceneMode.Single)`
  - 即主菜单进入签约链路的第一步已经改为切主游戏场景，而不是先开对话 panel
- `MarkDialoguePanelOpenedCommand` / `MarkDialoguePanelClosedCommand`
  - 仍维护对话入口相关状态字段

## 5. 启动流程事实（MainMenuFlowLauncher）

- `MainMenuFlowLauncher` 当前没有 `Awake()` 初始化逻辑。
- `Start()` 当前执行：
  - 防重入（`bootstrapped`）
  - 发送 `MarkMainMenuResReadyCommand`
  - 发送 `OpenMainMenuPanelCommand`
  - 可选自动演示流：等待 `autoRunDelaySeconds` 后发 `RequestOpenDialoguePanelCommand`
- 当前主菜单启动链路已经不再包含：
  - `UIKit.Config = new MainMenuUIKitConfig()`
  - `ResKit.InitAsync()`

## 6. 场景事实

- `Assets/Scenes/MainMenu.unity` 当前已直接包含 `MainMenuPanel`。
- `MainMenuPanel` 不再要求由 UI Kit 在运行时动态实例化。
- 主菜单入口现在更接近“场景直载 UI + 直接切场景”的轻量链路。

## 7. 交互组件事实

- `MainMenuExitButton`
  - 基于对象名关键字区分按钮行为：
    - 包含“退出”：点击执行退出
    - 包含“开始新游戏”：点击请求进入签约主场景
  - 带 Hover 缩放反馈
- `MainMenuEntranceDrop`
  - 对菜单子节点按“从上到下”顺序做入场下落 + 渐显动画
  - 支持 `unscaledTime`

## 8. 当前与旧链路的差异事实

- `MainMenuUIKitConfig.cs` 文件仍在仓库中，但 `MainMenuFlowLauncher` 当前不再使用它。
- 旧事实中的“打开 `dialogue_ui` 包，并关闭 `MainMenuPanel`”已不再是当前代码主路径。
- 当前 MainMenu 模块的主方向是：
  - 面板直接在场景里
  - 主菜单负责切 `SignScene`
  - 后续叠加对话和小游戏场景由签约链路自身处理
