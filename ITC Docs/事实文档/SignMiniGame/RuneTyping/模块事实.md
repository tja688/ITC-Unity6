# Contracting.RuneTyping 模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 脚本清单（代码事实）

- `Assets/Scripts/SignMiniGame/RuneTyping/RuneTypingPanel.cs`
- `Assets/Scripts/SignMiniGame/RuneTyping/RuneTypingQuickTestLauncher.cs`
- `Assets/Scripts/SignMiniGame/RuneTyping/RuneTypingGuideTag.cs`

## 2. 面板职责事实

- `RuneTypingPanel : UIPanel`
- 输入数据：`RuneTypingPanelData`
  - `GridSize`（4 或 5）
  - `RuntimeConfig`
  - `RoundConfig`（目标序列与网格布局）
- 输出数据：`RuneTypingResultPayload`

## 3. 状态机事实

- `Countdown`
- `Playing`
- `FeedbackCorrect`
- `FeedbackError`
- `ComboResolve`
- `Completed`

## 4. 输入与判定事实

- 输入通道：
  - 键盘方向 + 确认
  - 屏幕按钮（受平台/配置控制）
  - 网格点击可直接移动光标
- 边界外移动不记错误，但会触发边界反馈。
- 确认节流：`MinConfirmIntervalMs`。
- 判定逻辑：
  - 当前格符文 == 目标序列当前位置 => 正确推进
  - 否则 `errorCount++`
- 全部序列完成后提交 payload（`WasFallback=false`）。

## 5. 与全局流程连接事实

- 对话层发送：`BeginRuneTypingCommand`
- 面板提交后发送：`SubmitRuneTypingResultCommand`
- 关键回写字段：
  - `RouteQteErrorCount`
  - `RuneTypingGridSize`
  - `RuneTypingRunning/Completed`

## 6. QuickTest 事实

- `RuneTypingQuickTestLauncher` 支持：
  - 自定义 `clientId/gridSize/基线状态`
  - 热键重开（默认 `T`）
  - 超时检测日志

## 7. GuideTag 事实

- `RuneTypingGuideTag` 是空组件，用于引导系统标记。
