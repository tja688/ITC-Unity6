# Contracting.Settlement 模块事实

最后更新时间：2026-03-21（Asia/Shanghai）

## 1. 脚本清单（代码事实）

- `Assets/Scripts/SignMiniGame/Settlement/SettlementPanel.cs`
- `Assets/Scripts/SignMiniGame/Settlement/SettlementQuickTestLauncher.cs`
- `Assets/Scripts/SignMiniGame/Settlement/SettlementGuideTag.cs`

## 2. 面板职责事实

- `SettlementPanel : UIPanel`
- 输入：`SettlementPanelData`
  - 结算展示所需的聚合字段（文书/QTE/印章/灵魂/豆罐/满意度/小费/资金/Tier）
- 输出：`OnCompleted()`（无结构体 payload）

## 3. 状态机事实

- `Collect`
- `Evaluate`
- `Reward`
- `Narrate`
- `RouteNext`
- `Completed`

## 4. 展示与反馈事实

- 面板不做最终数值计算，计算在 `FinalizeClientContractCommand` 完成。
- 面板负责：
  - 汇总文本展示
  - Tier 视觉色调（good/neutral/bad）
  - 阶段化反馈流程（可跳过）
- 流程结束触发 `OnCompleted`，供上层恢复 Yarn 路由。

## 5. 与全局流程连接事实

- 上层对话命令链：
  - `BeginSettlementCommand`
  - `FinalizeClientContractCommand`
  - 打开 `SettlementPanel` 做反馈展示
- 展示后回写 Yarn：
  - `$satisfaction`
  - `$Sign_mistake`
  - `$money`
  - `$Nmber_of_sign_mistake`
  - `$Global_sign_mistake`
  - `$Route_SettlementTip`
  - `$Route_SettlementTier`
  - `$Route_SettlementFinalSatisfaction`

## 6. QuickTest 与 GuideTag 事实

- `SettlementQuickTestLauncher`
  - 支持配置 day/客户/满意度/资金/失误累计
  - 热键重开默认 `G`
  - 同样走 `Begin + Finalize + Panel` 正式链路
- `SettlementGuideTag` 为引导标记空组件。
